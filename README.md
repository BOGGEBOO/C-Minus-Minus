# C--
## TDP019 Projekt: Datorspråk

```C--``` är programmeringsspråk som ingen någonsin bör använda. Dess syntax är inspirerad av ```C++``` med vissa inslag från ```Python```. Det är skapat till projektkursen TDP019 med ruby och rdparse. 

För att ladda ned och använda språket, följ nedanstående instruktioner

```Bash
git clone https://gitlab.liu.se/antno464/tdp019.git && cd tdp019
./install.sh
```
